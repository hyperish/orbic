# 00. 개요와 범위 (ring)

> 상태: 역할·도메인 범위·레퍼런스(`loco.rs`)는 **확정**, 세부 모듈 구성은 **제안** · 기준일: 2026-11-17

`ring`은 하이퍼리쉬 프레임워크 패밀리의 **백엔드 프레임워크** 레포입니다. 공통 추상 계약은 [`hyperish/docs`](https://github.com/hyperish/docs)를 따르며, 코어 모델·상태·직렬화·API 규격 인터페이스는 [`hyper`](https://github.com/hyperish/hyper)를 단일 기준(`ref`)으로 참조합니다.

## 1. 확정된 역할과 도메인 범위

`ring`은 백엔드 개발과 운영에 필요한 도메인 전반을 다룹니다:

1. **데이터베이스(DB) & 영속성**: 스키마 정의, 마이그레이션, 쿼리 빌딩, 트랜잭션과 커밋/보상 지점 관리, 오브젝트 스토리지 연동.
2. **캐시(Cache) & 상태 조정**: 인메모리·분산 캐시 계층, 세션·레이트리밋 상태, 멱등 키(Idempotency-Key) 보관소.
3. **MSA & 서비스 간 통신**: 서비스 디스커버리, 고성능 내부 RPC/메시지 버스, 백그라운드 워커·작업 큐, 분산 추적(`TraceId`/`RequestId`).
4. **실시간 통신 (WS / WT)**: WebSocket(WS) 및 WebTransport(WT) 기반 양방향 스트리밍, 룸(Room)·프레즌스·시퀀스(`seq`) 상태 조율.
5. **인증·권한·외부 API 및 `lace` 웹 프로덕션 서빙**: 세션·토큰 인증, 요청별 접근 권한 검증·철회 즉시 반영(`hyperish/docs` `02-core-contracts.md` §6), 그리고 [`lace`](https://github.com/hyperish/lace)가 빌드한 DOM/웹 출력물의 **프로덕션 서빙·SSR 호스팅**을 담당합니다(로컬 개발용 프리뷰/데브 서빙은 `lace` 자체 내장).

## 2. 레퍼런스와 구현 전략 (확정)

| 축 | 레퍼런스 / 전략 | 채용 이유 |
|---|---|---|
| **백엔드 아키텍처 & DX** | **Loco (`loco.rs`)** | 라우팅·컨트롤러·모델/마이그레이션·백그라운드 워커·태스크가 하나로 정돈된 배터리 포함(batteries-included) 백엔드 생산성 |
| **선언적 매크로 & 순수 Rust 빌더** | **`hyper` DSL + GPUI식 가독성 높은 Rust 빌더** | 선언적 어트리뷰트/매크로로 간결하게 쓰되, 순수 Rust 빌더·체이닝만으로도 가독성이 좋으면 매크로 없이도 작성 가능 |
| **코어 수직화** | **`hyper` 코어(`ref`) 기반 + 호환 어댑터 분리** | `hyper-core`, `hyper-serde`, `hyper-api`를 그대로 참조해 웹(`lace`)·네이티브(`hera`)와 타입·계약을 무변환 수직 통합 |
| **성능 확보 (`unit optimization`)** | **고성능 검증 크레이트 포크 + 단계적 `unit optimization`** | 1단계로 불필요한 범용 추상화·미사용 피처를 제거하고 `hyper` 코어에 직결하며, 추후 병목 구간에 2단계(메모리 레이아웃·SIMD 등) 심화 개조 여지 확보 |

## 3. 책임 경계: 소유하는 것과 소유하지 않는 것

- **소유함**:
  - 서버 애플리케이션 수명주기(부트스트랩, 설정, 헬스체크, 그레이스풀 셧다운), DB/Cache/MSA/WS·WT 런타임 추상화, 백그라운드 잡 스케줄러, 서버 측 외부 호환 어댑터(HTTP/JSON, WebSocket, WebTransport 등).
- **소유하지 않음**:
  - 범용 직렬화·파서·상태 프리미티브와 공통 API 계약 매크로 정의(`hyper` 소관)
  - 브라우저 DOM 렌더링 및 클라이언트 UI(`lace`, `hera` 소관)
- **의존 방향**:
  - `ring` → `hyper` (단방향). `ring`의 코어 도메인 로직은 특정 클라우드 벤더나 외부 프로토콜에 종속되지 않으며, 어댑터 계층(`ring-adapter-*`)을 통해 외부 세계와 연결됩니다.
